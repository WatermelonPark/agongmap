# 요청: GA 내부 트래픽에서 대표 휴대폰·태블릿 접속도 빼기 (2026-10-19, 로컬 마케팅-데이터 세션)

## 왜
- 마케팅 OKR(12월까지 블로그발 사이트 세션 주 18, 주요 이벤트 28일 14)을 GA로 잰다. 지금 주간 세션이 60건대라 대표 본인 접속 몇 건만 섞여도 지표가 흔들린다.
- 10-19 GA4 관리 화면에서 내부 트래픽 규칙(IP 기준)을 바로잡고 'Internal Traffic' 데이터 필터를 활성으로 바꿨다(대표 승인). 그런데 IP 규칙은 고정 IP인 PC만 거른다. 휴대폰(이동통신)은 IP가 계속 바뀌어 걸러지지 않는다.

## 원하는 동작
- 대표 기기에서 한 번만 표식 주소(예: `?internal=on`)로 들어오면 그 기기의 localStorage에 표식을 저장하고, 그 뒤 모든 페이지의 GA 전송에 `traffic_type: 'internal'`을 붙인다. GA 필터가 이미 `traffic_type = internal`을 제외하므로 GA 쪽 설정은 더 바꿀 필요가 없다.
- `?internal=off`로 표식을 지운다.
- 대상: `gtag('config', …)`를 부르는 모든 페이지(홈 `index.html`은 `send_page_view:false`로 수동 page_view, 생성 페이지·손 페이지는 config 기본 page_view). 홈 수동 page_view와 이벤트에도 같은 값이 실려야 한다(config 매개변수로 넣으면 이후 이벤트에 따라간다).
- 표식 이름과 주소 값은 공개 저장소에 그대로 보여도 괜찮다(남이 쓰면 그 사람 접속이 빠질 뿐 개인정보 문제는 없음). 다만 IP 값은 어디에도 적지 않는다.

## 확인 방법(제안)
- 시험: 모든 `gtag('config'` 호출이 같은 내부 표식 조각을 거치는지(손 페이지 포함, `test_site_nav`처럼 저장소 HTML 전체 대조). 변이: 한 페이지에서 조각을 빼면 빨개짐.
- 개인정보처리방침 `#ga-events` 전송 목록에 `traffic_type`(내부 표식 기기만) 한 줄 추가(`test_privacy_ga_events`).
- 배포 뒤 대표 휴대폰에서 `?internal=on` → GA 실시간 '테스트 데이터 필터 이름'이 아니라 보고서에서 빠지는지 마케팅-데이터가 확인한다.
