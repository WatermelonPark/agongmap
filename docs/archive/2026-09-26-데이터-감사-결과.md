# 데이터 경로 감사 결과 (2026-09-26, 클라우드 세션)

## 계기

2026-09-24~26 데이터 배치가 다섯 회 연속 커밋을 하지 않았다. 원인은 시험 하나의 `import yaml`이었다. 커밋 잡을
setup-python 3.12로 고정한 뒤로 그 환경에는 `pytest`·`pillow`만 있어 게이트가 빨개졌고, 개발 컨테이너(3.11, 시스템
yaml)에서는 초록이었다. 같은 유형, 곧 "개발 환경에서는 초록인데 배치에서는 데이터 커밋을 막는 것"과 "데이터가
조용히 틀리는 것"을 데이터 경로 전체에서 찾았다.

방법: 수집(`update_adv_data`)·생성기 다섯·게이트 시험·감시·워크플로를 나눠 훑고, 발견마다 CI와 같은 조건(3.12,
`pytest pillow`만, `GITHUB_ACTIONS=1`, `TZ=UTC`, depth 200 클론)에서 재현한 뒤 독립 검증 두 번을 거쳤다. 수정은
세 갈래로 나눠 각각 리뷰했고, 합친 브랜치를 배치 커밋 잡과 같은 순서(생성기 → 게이트 → 보고 도구)로 다시 돌렸다.
