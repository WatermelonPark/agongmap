# 검색엔진·AI 검색 등록 절차 (대표가 할 일)

백로그 50 요청 2-3. **대표 계정이 필요한 일만** 모았다. 코드 쪽(robots·sitemap·구조화 데이터·llms.txt·
llms-full.txt)은 개발 세션이 끝냈다(2026-10-27). 아래는 한 번만 하면 되는 등록이고, 다 합쳐 20분쯤 걸린다.

사이트 주소는 `https://www.agongmap.co.kr` 이다.

## 1. 구글 서치콘솔

1. <https://search.google.com/search-console> 에 구글 계정으로 들어간다.
2. 속성 추가 → **URL 접두어** 를 고르고 `https://www.agongmap.co.kr` 을 넣는다(도메인 속성은 DNS 를 만져야 해서
   접두어 쪽이 빠르다).
3. 소유 확인은 **HTML 태그** 를 고른다. 화면에 나오는 `<meta name="google-site-verification" content="...">` 의
   content 값을 개발 세션에 알려 주면 홈에 넣고 배포한다. 배포 뒤 '확인' 을 누른다.
   - 바로 확인하고 싶으면 **HTML 파일 업로드** 대신 위 방법을 쓴다. 파일 업로드는 저장소에 파일을 넣어야 해서
     어차피 개발 세션을 거친다.
4. 확인이 끝나면 왼쪽 **Sitemaps** 에서 `sitemap.xml` 을 제출한다.
5. 며칠 뒤 **페이지** 화면에서 '색인 생성됨' 수가 늘어나는지 본다.

## 2. 빙 웹마스터 도구

1. <https://www.bing.com/webmasters> 에 들어간다.
2. **구글 서치콘솔에서 가져오기** 가 있으면 그걸 쓴다(1번을 먼저 끝내면 클릭 몇 번으로 끝난다).
3. 가져오기를 쓰지 않으면 사이트를 추가하고, 소유 확인은 **메타 태그** 를 골라 content 값을 개발 세션에 준다.
4. **Sitemaps** 에서 `https://www.agongmap.co.kr/sitemap.xml` 을 제출한다.
5. 빙 색인은 ChatGPT 검색·코파일럿 인용과 이어져 있어, AI 검색 목표에는 구글만큼 중요하다.

## 3. 네이버 서치어드바이저

1. <https://searchadvisor.naver.com> 에 네이버 계정으로 들어간다. 이미 사이트가 등록돼 있으면 3번으로 간다.
2. 웹마스터 도구 → 사이트 등록 → 주소를 넣고, 소유 확인은 **HTML 태그** 를 골라 content 값을 개발 세션에 준다.
3. **요청 → 사이트맵 제출** 에서 `sitemap.xml` 을 넣는다. 새 섹션(`/city/`·`/gtx/`·`/danji/`·`/column/`)은 사이트맵에
   자동으로 들어가므로 따로 넣을 것은 없다.
4. **요청 → 웹페이지 수집** 에 새 글 주소를 하나씩 넣으면 수집이 빨라진다(글을 올린 날 한 번).

## 4. 개발 세션이 받아서 하는 일

- 소유 확인 메타 태그 세 개(구글·빙·네이버)를 홈 `<head>` 에 넣고 배포한다. 값만 주면 된다.
- 등록이 끝나면 `docs/` 에 등록 날짜를 적는다.

## 5. 이미 되어 있는 것 (확인용)

| 항목 | 상태 |
|---|---|
| `robots.txt` | 전체 허용. GPTBot·ChatGPT-User·OAI-SearchBot·PerplexityBot·ClaudeBot·Google-Extended·Googlebot·Bingbot·Yeti 를 이름으로 허용 |
| `sitemap.xml` | 모든 주소에 `lastmod`. 콘텐츠 글과 섹션 목록도 배치가 넣는다 |
| 구조화 데이터 | 글마다 `Article`(datePublished·dateModified·author·publisher), `FAQPage`, `BreadcrumbList`. 홈은 `WebPage.dateModified` |
| 화면 수정일 | 홈과 시도 리포트에 '페이지 수정 YYYY-MM-DD' |
| `llms.txt` | 사이트 요약과 섹션별 최신 글 목록 |
| `llms-full.txt` | 글 전문(표의 숫자는 배치가 다시 채운다) |
| `feed.xml` | 주간·시도·월간에 더해 콘텐츠 글이 항목으로 들어간다 |

## 6. CCBot(학습 말뭉치) — 대표 결정이 남아 있다

`robots.txt` 는 지금 CCBot 을 막지 않는다(전체 허용). 학습 데이터 수집을 막고 싶으면 알려 주면 두 줄을 넣는다.
막아도 ChatGPT·Perplexity 의 **검색 인용** 에는 영향이 없다(그쪽은 GPTBot·OAI-SearchBot·PerplexityBot 이 본다).
