# 아공맵 화면 마감 점검

대표 지적이 반복된 원칙이 CLAUDE.md '화면 설계 원칙'에 있다. 그 원칙을 먼저 보고, 아래 마감 항목을 더한다.

## 원칙 대조(먼저)

- **설명·범례는 콘텐츠 아래, 짧게.** 375px 첫 화면에서 콘텐츠가 설명보다 먼저 보이는지.
- **한 개념 한 이름**: '적정물량', 단위 '세대', 신호등 '적음·보통·많음', 판정 '부족·균형·여유'.
- **날짜 두 단계**: 읽는 자리 '9/28'·'2026년 8월', 좁은 자리 '26.9.28'·'26.8'. 정본 `sido_zones.day_text` 등, 홈 거울 `_md` 등.
- **가로 축 오른쪽 = 많음**(부족 → 여유, 하락 → 상승, 적음 → 많음).
- **데스크톱(1024px+)은 `desk.css` 한 곳**에서 `data-desk` 종류로.

## 색(2026-11-11 색 감사 뒤 규칙)

| 쓰임 | 정본 | 쓰지 않는 곳 |
|---|---|---|
| 틀(내비·선택된 단추·주요 단추·링크·요약 표지) | `site_nav.BRAND_TOKENS` 남색 `--brand` | 지도·표·그래프 |
| 결론 숫자 강조·분류 태그 | `--mark`(형광)·`--mark-bg`·`--mark-ink` | 넓은 면 바탕(베이지 금지 — `audit_design` 웜색) |
| 흰 바탕 등락 글자 | `UP_INK`·`DN_INK` 한 벌 | — |
| 그래프 계열 | `SERIES_COL`(매매 빨강·전세 보라·공급 초록) | 상승·하락 표시 |
| 판정 부족 단계 | 빨강의 짙기(심각 채움·매우 연함·부족 더 연함) | 노랑(신호등 '보통'과 겹침) |

새 색을 박지 말고 토큰을 쓴다. 같은 뜻에 두 번째 색이 생기면 정본으로 모으고 `test_brand_color` 에 잠근다.

## 마감 항목

- **정렬**: 같은 줄 카드는 같은 안쪽 여백·같은 기준선, 반복 요소(칩·날짜·숫자)는 카드마다 같은 자리.
- **숫자**: 열로 늘어선 숫자는 `font-variant-numeric: tabular-nums`, 오른쪽 맞춤. 부호는 표시값 기준.
- **누름 면** 40px 이상, 누를 수 있는 것은 누를 수 있게 보인다(링크 밑줄·단추 테두리).
- **넘침**: 375px 가로 스크롤 금지. 넓은 표는 그림자 단서가 있는 스크롤 상자.
- **빈 상태**: 데이터가 빈 회차에도 사유 한 줄(`/monthly/` `_why_empty` 처럼).
- **둥근 모서리**: 잰 것은 각지고 누르는 것만 둥글다(`--r-touch`, `audit_design` 의 `RADIUS_*`).
- **카드 남용 금지**: 테두리·그림자는 따로 떼어 보여야 할 것 하나에만.

## 점검 도구

- `python3 tools/audit_design.py`: 공유 시트·폰트·800 굵기·대문자·자간·radius·금색·웜색·장식 그림자.
- 화면 캡처: 정적 서버 + Playwright, 375·1280px. 사람이 볼 캡처는 `deviceScaleFactor: 2`.
