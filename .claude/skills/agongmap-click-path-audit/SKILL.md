# 아공맵 누름 경로 점검

함수마다 따로는 맞는데, 이어서 부르면 서로를 되돌리는 결함을 찾는다. 이 사이트에서 실제로 났던 꼴이다:
요청한 뒤 사람이 고른 보기를 늦게 온 데이터가 덮었다(`GT_SEQ`, 10-10 리뷰). 통계 파일을 못 받은 날 순위 입구가 빈 화면을 남겼다.

## 대상(홈 스크립트는 `tools/home_src.py` 로 읽는다)

| 입구 | 약속 | 상태·함수 |
|---|---|---|
| 홈 모드 단추 셋(공급 현황·주간 시세·월간 시세) | 같은 카드에 그 지도 하나 | `mapMode`·`priceModel`, N 배지(`ADV.fresh`) |
| 지도·그래프·표 단추 | 시세 모드에서는 시세 탭을 연다 | 2026-10-04 결정 |
| 시세 탭 시장동향 보기(순위·지도·그래프·표) | 기본 지도, 순위·지도는 한 상자 | `drawNationMap`·`gm-r`·`gm-m` |
| 해시 `#stats-market-<week\|month>~코드`(`-t` 는 표)·`-rank` | 그 지역 그래프·표·순위 | `openTrendRegion`(셋째 인자 'r'), `GT_SEQ` |
| 순위에서 연 지역 그래프의 뒤로 가기 | 순위로 돌아간다 | `TR_BACK`(`test_market_rank_view`) |
| 지역 선택 상자 | 판정 단위는 `DISPLAY_ORDER`, 구 있는 시는 '성남 전체' | `sggPickOf`·`sggCityName` |
| 시도 리포트 주간·월간 지도 단추 | 기본 주간 | `zone.js` |
| 콘텐츠 허브 칩·'더 보기' | 그 지역·분류 글만 | `make_content_pages.city_chips` |

## 점검 순서

1. 로컬 정적 서버(8321)를 띄우고 Playwright 로 연다. 휴대폰(375px)과 데스크톱(1280px) 둘 다.
2. 단추마다 **누르기 전 상태 → 누른 직후 → 데이터가 다 온 뒤(네트워크 idle)** 세 번 화면 상태를 기록한다: 켜진 단추, 보이는 상자, 주소 해시, 제목 글자.
3. **연달아 누르기**: 데이터가 오기 전에 다른 보기를 누른다. 늦게 온 응답이 사람이 고른 보기를 덮으면 결함이다.
4. **느린·끊긴 망**: `page.route` 로 `data-trend.json` 등을 늦추거나 실패시켜, 빈 화면 대신 다시 시도 단추·안내가 남는지 본다.
5. **뒤로·앞으로**: 해시 입구로 들어와 뒤로 가기를 눌렀을 때 약속한 화면인지.
6. **새로고침**: 해시가 남은 주소로 새로고침했을 때 같은 화면인지.

## 결함을 찾으면

- 실패하는 시험을 먼저 만든다. 홈 스크립트 시험은 node 로 실제 함수를 돌리는 꼴이 이 저장소의 관례다(`test_home_stats_runtime`·`test_market_rank_view`).
- 고친 뒤 판 표식 다섯 개를 함께 올린다(CLAUDE.md `sw.js` 행).
