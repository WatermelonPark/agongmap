# 사이트 콘텐츠 원고 (`content/`)

여기 둔 마크다운이 `/city/`·`/gtx/`·`/danji/`·`/column/` 페이지의 **정본**이다. 페이지(HTML)는 배치가 굽는다 —
출력물을 손으로 고치면 다음 배치가 되돌린다. 생성기는 `tools/make_content_pages.py`.

## 파일 자리

```
content/<섹션>/<slug>.md      섹션 = city · gtx · danji · column
content/<섹션>/img/*.png      이미지(본문에서 상대 경로로)
```

`slug` 는 영소문자·숫자·붙임표만 쓴다. 그대로 주소가 된다(`/city/incheon-2027-moveins/`).

## 프런트매터

```yaml
---
title: 2027년 인천 아파트 입주물량, 전세 오름세가 시험대에 섭니다
summary: 한 문단 요약. 페이지 첫 블록과 검색 설명문, AI 답변에 그대로 쓰인다.
date: 2026-10-27            # 작성일 — 처음 올린 날. 바꾸지 않는다
updated: 2026-10-27         # 최종 갱신일 — 글을 고칠 때마다 바꾼다
section: city               # 폴더 이름과 같아야 한다
region: 인천                # 선택. 쓰면 그 지역 공급 리포트로 가는 링크가 붙는다
sources:                    # 선택이지만 권장. 기관명과 자료명
  - 국토교통부 주택건설실적통계(인허가·착공·준공)
faq:                        # 선택. 2~4개. FAQPage 구조화 데이터로 나간다
  - q: 2027년 인천 입주 물량은 얼마나 되나요
    a: 아래 표의 합계와 같습니다.
---
```

필수는 `title`·`summary`·`date`·`updated`·`section` 다섯이다. 하나라도 빠지거나 형식이 어긋나면 **배치가 선다**
(반쯤 만든 페이지를 내보내지 않는다). `summary` 는 40~120자다.

## 본문에서 쓸 수 있는 것

`## ###` 제목, 문단, `- ` 목록, `1. ` 목록, `> ` 인용, `**굵게**`, `` `코드` ``, `[글](주소)`, `![대체글](이미지)`,
마크다운 표. 원고의 `<태그>` 는 글자 그대로 나간다(스크립트가 실행되지 않는다).

## 숫자는 자리표로 — 손으로 적지 않는다

원고에 숫자를 적으면 그 글은 쓴 날에 멈춘다. 배치는 매일 도는데 글만 옛 숫자를 말하게 된다. 그래서 사이트
데이터에 있는 숫자는 자리표로 적고, 생성기가 매 배치 채운다. **모르는 자리표·없는 지역은 실패다**(빈 표를
내보내지 않는다).

| 자리표 | 나오는 것 |
|---|---|
| `{{table:moveins:인천:2027}}` | 그 해 분기별 입주물량과 합계 |
| `{{table:moveins:인천}}` | 연도별 입주물량(예정 포함) |
| `{{table:supply:인천}}` | 공급 판정 요약(적정물량·앞으로 3년·재고·누적 과부족·판정) |
| `{{table:stats:인허가:인천}}` | 계열 최근 12기간 — 인허가·미분양·전세가율·준공·착공 |
| `{{table:weekly:인천}}` | 최근 8주 매매·전세 변동률 |
| `{{table:weekly:분당구}}` | 시군구도 된다 — 그곳의 최근 8주 변동률(이름이 겹치면 `고양 덕양구` 처럼 구까지) |
| `{{table:moveins:부천}}` | 도시(시군구)는 연도별 입주물량 |
| `{{table:moveins:부천:2027}}` | 도시는 그 해 **구별** 입주물량과 합계(시도는 분기별) |
| `{{table:complexes:부천:2027}}` | 그 해 입주 단지 목록 — 입주월·단지·구·세대 |

문장 안에 한 값만 넣을 때는 `{{v:...}}` 로 같은 인자를 쓴다.

- `{{v:moveins:인천:2027}}` → `26,935세대`
- `{{v:supply:인천}}` → `8,033세대 여유(1년 적정물량의 0.3배)`
- `{{v:weekly:인천}}` → `+0.02%`
- `{{v:stats:미분양:인천}}` → 최신 기간 값
- `{{v:share:평택:2027}}` → `224%` (그 해 물량이 적정 입주량의 몇 %인가)
- `{{v:streak:분당구}}` → `84주 연속 상승(10월 19일 조사)` · 전세는 `{{v:streak:분당구:전세}}`
- `{{v:need:부천}}` → `6,030세대` (그 도시의 한 해 적정 입주량)
- `{{v:pop:부천}}` → `753,731명(2026년 9월 주민등록)`
- `{{v:peak:부천}}` → `2032년 3월 1,859세대` · 한 해 안에서 고르려면 `{{v:peak:부천:2027}}`
  (단지 이름은 자리표에 없다 — 원천의 이름이 길어 문장에 그대로 넣기 어렵다. 단지는 글이 쓰고 숫자만 받는다.)

**단위는 자리표에 이미 들어 있다.** `{{v:moveins:부천:2027}}` 은 `3,962세대` 로 바뀌므로 뒤에 '세대'를 또
쓰면 '3,962세대세대' 가 된다(2026-10-27 첫 19편에서 44곳이 그랬다). 비율도 `%` 까지 들어 있다.

도시(시군구) 숫자는 `tools/data/city_moveins.json` 에서 온다. 그 파일은 원고의 `region` 과 자리표에 적힌
도시를 읽어 배치가 만든다 — 새 도시를 쓰면 다음 배치에서 자동으로 들어온다(손 목록 없음).

지역 이름은 화면 이름(`광주·전남`)과 내부 키(`전남광주`) 둘 다 받는다.

## 올리기 전에

```bash
python tools/content_check.py          # 전수 검사 — 파일과 줄 번호로 알려 준다
python tools/make_content_pages.py     # 통과하면 굽는다
```

원고가 규약을 어기면 여기서 바로 멈추고 이유를 말한다. 통과하면 페이지·섹션 목록·홈 '최근 리포트'·
`sitemap.xml` 이 함께 갱신되고, 이어서 `make_feed.py`·`make_llms_txt.py` 가 피드와 `llms.txt`·`llms-full.txt` 에 싣는다.
배치(클라우드·로컬)는 이 순서를 이미 담고 있다.
